# 설문 결과 집계표

5점 척도(1~5점) · 5개 문항 설문의 응답을 입력하면 문항별 평균, 점수 분포, 긍정 응답 비율(4~5점), 최고·최저 문항을 자동으로 계산해 보여주는 단일 HTML 페이지입니다.

- 응답 한 건씩 입력하거나(키보드 숫자 1~5 + Enter), 엑셀에서 5개 열을 복사해 여러 건을 붙여넣을 수 있습니다.
- 문항 이름은 페이지에서 바로 바꿀 수 있습니다.
- '요약 복사', 'CSV 복사'로 결과를 보고서나 엑셀에 옮길 수 있습니다.
- 입력한 응답은 사용하는 브라우저(localStorage)에만 저장됩니다. 서버로 전송되지 않습니다.

## 배포

빌드 과정이 없는 정적 사이트입니다. Vercel에서 `index.html`이 그대로 배포됩니다.

- 서비스 주소: https://survey-tally-kappa.vercel.app
